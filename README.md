# Home-Services-Management-Platform-node
# 家政服务平台（管理端+用户手机端）
### 1、项目介绍

基于 Node.js + Express + Vue3 + uni-app 开发的家政服务管理平台，采用前后端分离架构，包含 Web 管理端 + 手机用户端，通过统一 RESTful API 实现服务发布、预约下单、订单派单、结算及评价的完整业务闭环。

### 2、系统功能
⭕ 管理后台

· 登录

· 首页（数据看板）

· 服务管理：服务分类 | 服务项目

· 订单管理：订单列表 | 订单派单 | 订单结算

· 服务人员管理：服务人员列表

· 用户管理：用户列表

· 评价管理：评价列表

· 系统管理：菜单管理 | 角色管理 | 账号管理

⭕ 用户端前台（手机端）

· 登录 | 注册

· 首页

· 服务分类

· 服务详情

· 预约下单

· 我的订单 | 订单详情

· 评价服务

· 我的（个人中心）

### 3、技术栈
- 后端：Node.js + Express
- 数据库：MySQL 8.0
- 管理端：Vue 3 + Element Plus + Pinia
- 用户端：uni-app + Vue 3
- 其他：Vue Router + Axios + ECharts + JWT
- 架构：前后端分离 + RESTful API + MVC + RBAC
### 4、项目亮点
- 真实业务闭环：覆盖服务发布、预约、派单、结算、评价等完整家政服务流程。
- Node 后端实践：基于 Express + MVC 分层架构，结合 JWT、中间件鉴权等技术。
- 多端开发实践：Vue3 构建 Web 管理端，uni-app 构建手机用户端，掌握跨端开发流程。
- RBAC 权限控制：实现角色、菜单、账号关联，支持菜单级与按钮级权限控制。
- 数据库实践：涉及用户、服务、订单、评价、角色、菜单等多表关联，提升 MySQL 数据库设计能力。
- 全栈学习价值：覆盖前端、后端、数据库、权限及业务逻辑，适合 Node.js 全栈开发实战学习。
